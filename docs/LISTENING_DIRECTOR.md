# Listening director (first integration)

This is a bounded generation-first workflow, not an autonomous songwriter or a calibrated artistic judge. It reuses the existing artist runner and the installed Studio MOSS CPU captioner, independently of the retained P5 calibration. The neutral prompt contains no song title, expected style, lyrics, desired emotional arc, or leading requirement checklist. Raw responses and partial field extraction are retained; every extracted observation remains unverified. The two contiguous excerpts cannot establish global structure or stereo quality. The downstream review packet reveals intent only after listening and includes native acoustic and lyric-screen evidence. No score, automatic acceptance, winner selection, revision, finishing, external service, model download, or automatic retry.

From the repository root, `director.cmd --demo` is a no-inference plan. Only with explicit operator approval, `director.cmd --demo --confirm-run` permits one fresh original direct-native song, one local recognition, and two CPU listening excerpts. The demo is an original contemporary folk-soul brief, not a comparison of the previous blues-soul recordings. For private songs, use `local/brief.json` and `local/intent.json` with the demo schemas and direct-native route. The new workflow caps requested duration at 208 s; actual verified audio must not exceed 210 s. Hard score constraints require the existing reviewed-native runner. Native journals and stable-idle barriers remain; the new launcher takes both the draft and critic locks and checks stable idle before each new captioner attempt. An existing completed native take and completed listening receipts are reused. An ambiguous attempt stops, not retries. A listening failure retains the native take; inspect evidence before proceeding. Do not delete journals to retry.

Output: `results/director-output.txt` and `results/drafts/artist-<brief digest>/neutral-listening/review-packet.json`, including original audio identity, raw neutral observations, intended musical direction, measurements, and review guidance. The packet is for a subsequent director (assistant or human) decision; it does not yet implement a language-model composer, intent comparison or autonomous prompt revision. No new generation or listening inference is authorized by this code change alone. CI checks software behavior using fixtures, not Studio audio quality or live inference.
