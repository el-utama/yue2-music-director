# Temporal evidence and phonetic alignment

Source audit pinned to upstream YuE2 Studio ca37d2d3ea96f3c7073167de0e5e1eb3b4ec2f25:
- [MCP](https://github.com/timoncool/YuE2-Studio/blob/ca37d2d3ea96f3c7073167de0e5e1eb3b4ec2f25/crates/music-server/src/mcp.rs): lyrics_recognise returns recognised text; existing observed responses had provider/text only. karaoke_make writes a song's enhanced LRC. library_song_get with response_format detailed retains metadata.lrc; concise removes it.
- [lyrics_sync.rs](https://github.com/timoncool/YuE2-Studio/blob/ca37d2d3ea96f3c7073167de0e5e1eb3b4ec2f25/crates/music-server/src/lyrics_sync.rs): heard_words consumes raw ASR word starts and filters hallucinated segments. align_lyrics_words matches expected words and interpolates missing words by length; align_lyrics also interpolates missing lines. enhanced_lrc serializes starts without flags distinguishing observations from interpolation. Thus expected text and plausible timestamps cannot prove sung fidelity or actual phoneme timing.

`timing-evidence --source ORIGINAL.flac --song-id SONG_ID --lyrics LYRICS.txt --baseline-asr BASELINE.json --language en --duration MEASURED_SECONDS --out NEW_REPORT.json`

Read-only lookup of existing detailed library metadata and file identity. No karaoke generation, ASR inference, downloads, or library mutation. Strictly parses plain/enhanced LRC with ordered starts in supplied duration and exact reference text/order after whitespace normalization. Unsupported formats, missing metadata, or mismatch block evidence; no fallback estimation. English ASR disagreements can be associated with the reference line, never a specific phoneme or observed timestamp. Existing LRC may be edited/imported/stale, and source file identity is not timing provenance. A valid report is still display anchors only and cannot authorize corrections.

Next research: acquire raw recognised word starts/ends with explicit recording hash and model provenance, distinguish observed versus interpolated timing, then evaluate a singing-compatible phonetic aligner with appropriate language coverage. The pinned native MCP interface does not expose verified phoneme timing. SoulX input requires already-aligned metadata and is not itself proof of an available alignment tool. Avoid another recognition pass until the output contract and intended use are established.
