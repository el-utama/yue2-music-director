# Modular creative core — first P0 increment

Separate provider transport, Composer, Lyricist, editorial reviewer, response contracts and checkpoint coordinator. Text-only; not the completed autonomous agent. No generation or Studio calls. Every confirmed text stage records an immutable attempt and validated receipt; completed stages are reused only for identical input, provider and prompt. An unresolved attempt blocks further work, does not replay upstream work or trigger downstream calls. Recovery UI/explicit failed-stage reauthorization and independently versioned cache invalidation are still pending. Changing an upstream artifact requires a new job; never delete journals as a workaround.

Composer starter advice independently summarized from pinned [Studio writing code](https://github.com/timoncool/YuE2-Studio/blob/bfd35a0e594cbd1268557833001d5675ebbdd2d3/app/services/songWriting.ts) and [MCP skill](https://github.com/timoncool/YuE2-Studio/blob/bfd35a0e594cbd1268557833001d5675ebbdd2d3/docs/mcp-skill.md). Lint guidance is advisory, not model enforcement. Installed writing_guide/writing_examples still need live verification. No upstream code or lyric corpus copied. Lyricist uses original generation and coarse text diagnostics only; no claim of verified originality or professional quality.

Provider configuration is explicit HTTPS OpenAI-compatible chat/completions URL, MUSIC_LLM_URL, MUSIC_LLM_KEY, MUSIC_LLM_MODEL; optional MUSIC_LLM_COMPOSER_MODEL, MUSIC_LLM_LYRICIST_MODEL, MUSIC_LLM_REVIEWER_MODEL, MUSIC_LLM_DIRECTOR_MODEL. No assumed NVIDIA/Nemotron endpoint or model name. Only --confirm-text authorizes sending prompt/creative text to configured provider. No credentials or audio included in receipts. Private results under results/creative. No fallback or automatic retries. Real Nemotron compatibility not yet validated.

Windows launcher creative.cmd takes --job NAME --request "idea" --language en --duration 195; plan only by default. Add --confirm-text to run text stages. This is a development entry point, not a request for operator testing yet. Next integrate native draft/listening and tested recovery, then one live end-to-end validation. No extra GPU test required for this increment.
