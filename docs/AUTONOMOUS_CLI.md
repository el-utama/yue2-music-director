# Autonomous CLI (development, not yet live-validated)

One natural-language request drives separate Composer, Lyricist, editorial reviewer, native production, neutral listening and advisory Director judgment. Existing creative and native journal contracts are reused; no separate song_create implementation. The default is plan-only. Confirmed scope: four text completions sent to explicitly configured HTTPS provider (including brief/lyrics and selected text evidence for final review), one native song, one explicit ASR, two CPU excerpts. No raw audio, file paths, credentials or raw native logs are sent by the final review payload. Native Studio automatic karaoke may also run as configured by Studio. No automatic revision or finishing; result provisional or review required.

Development entry: `music.cmd --confirm-run` prompts for the idea, defaults to English and a 195-second cap, generates a local job ID. Override via --language and --duration. Resume known job using `music.cmd --job JOB --confirm-run`; it reads retained request and parameters. The provider must be configured as described in [Creative Core](CREATIVE_CORE.md). No assumption about the actual Nemotron API. No automatic paid fallback. Do not ask the operator to test until CI and provider setup are reviewed.

Artifacts: results/autonomous/JOB (private), separate creative receipts, production native journal, listening packet and final result. All normal stages run sequentially. Shared draft and critic locks protect existing runner paths. Completed native reports and validated listening receipts are reused; an unresolved attempt stops safely. No automatic retry on ambiguous text/ASR/captioner/native submissions. If MOSS unavailable before an attempt, the same job may resume without resynthesizing. An abrupt process crash can leave a lock; inspect process/ownership before manual recovery; automatic stale-lock recovery and background service not implemented. Job configuration immutable; changing model, prompt or request may require a new job. Current CLI does not reliably enforce arbitrary natural-language hard constraints, preserve supplied lyrics verbatim, or support approved revisions; use simple original vocal-song requests only. This is not the finished P0 acceptance gate.

Tests inject provider and listening failures and mock native stage reuse; existing native tests cover actual journal/receipt handling. CI does not connect to real Nemotron or Studio. Live provider and full end-to-end integration still pending. Knowledge bases and artist profiles not shipped.
