# Alpha 6 — native prosody evidence

Pass a saved Studio lyrics_syllables response to fidelity-audit with --native-syllables FILE. Every line must match the reference in order and have a positive integer count. Repeated chorus lines are retained by occurrence. Invalid native input fails closed; omission explicitly uses the rough English estimate. No MCP calls, audio jobs or score edits.

The native count is still heuristic, not a phonetic segmentation or a syllable-to-note alignment. Upstream reference: https://github.com/timoncool/YuE2-Studio/blob/ca37d2d3ea96f3c7073167de0e5e1eb3b4ec2f25/crates/music-server/src/score/phrasing.rs describes automatic phrase placement for scores without section labels; its syllable count is spelling-based. The song_create lyric_timing description in the same upstream revision's crates/music-server/src/mcp.rs describes section timing, not guaranteed exact line/note alignment. The installed Studio build may differ.

For the B sample, all five confirmed issue lines still have more note events than native syllables in their approximate bar spans. No justified automatic note insertion or timing modification. Next proposed experiment: keep B's frozen ABC, lyrics, style, acoustic seed and settings, change only lm_seed (token draw seed) for one explicitly authorized new performance. Compare human fidelity at the same six locations and check other phrases for regression. A single alternate draw can test sensitivity, not establish a causal remedy or general success rate. Do not change defaults silently or resubmit ambiguous jobs. No new generation in this alpha.
