# Modular creative core — first P0 increment

Separate provider transport, Composer, Lyricist, editorial reviewer, response contracts and checkpoint coordinator. Text-only; not the completed autonomous agent. No generation or Studio calls. Every confirmed text stage records an immutable attempt and validated receipt; completed stages are reused only for identical input, provider and prompt. An unresolved attempt blocks further work, does not replay upstream work or trigger downstream calls. One explicit retry of an unresolved role is implemented; successful receipts cannot be replayed. Composer/Lyricist semantic checks precede success receipts for new direction policies. Recovery UI and general cache migration remain pending. Changing an upstream artifact requires a new job; never delete journals as a workaround.

Composer starter advice independently summarized from pinned [Studio writing code](https://github.com/timoncool/YuE2-Studio/blob/bfd35a0e594cbd1268557833001d5675ebbdd2d3/app/services/songWriting.ts) and [MCP skill](https://github.com/timoncool/YuE2-Studio/blob/bfd35a0e594cbd1268557833001d5675ebbdd2d3/docs/mcp-skill.md). Lint guidance is advisory, not model enforcement. Installed writing_guide/writing_examples still need live verification. No upstream code or lyric corpus copied. Lyricist uses original generation and coarse text diagnostics only; no claim of verified originality or professional quality.

Provider configuration is explicit HTTPS OpenAI-compatible chat/completions URL, MUSIC_LLM_URL, MUSIC_LLM_KEY, MUSIC_LLM_MODEL; optional MUSIC_LLM_COMPOSER_MODEL, MUSIC_LLM_LYRICIST_MODEL, MUSIC_LLM_REVIEWER_MODEL, MUSIC_LLM_DIRECTOR_MODEL. No assumed NVIDIA/Nemotron endpoint or model name. Only --confirm-text authorizes sending prompt/creative text to configured provider. No credentials or audio included in receipts. Private results under results/creative. No fallback or automatic retries. Live hosted Nemotron structured output and autonomous integration were subsequently verified on the operator host; current details are in [Autonomous CLI](AUTONOMOUS_CLI.md).

Windows launcher creative.cmd takes --job NAME --request "idea" --language en --duration 195; plan only by default. Add --confirm-text to run text stages. This standalone text entry point remains independent; the active autonomous pipeline already integrates native draft/listening and bounded recovery. No extra GPU test required.
